# Bus Simulator 2027

Bus Simulator 2027 adalah game simulator mengemudi bus kota. Pemain mengemudikan bus di rute kota, menjemput dan menurunkan penumpang, serta menjaga jadwal perjalanan.

## Fitur rencana

- Rute bus kota dengan halte dan jadwal
- Sistem penumpang dan pendapatan
- Kontrol kemudi, gas, rem, dan pintu bus
- Mode karier dengan tingkat kesulitan bertahap
